## 为什么好的图标设计如此重要？

图标是用户界面的"无声语言"。一个好的图标集能让产品看起来专业、一致、值得信赖。

SVG 是图标设计的天然格式——但设计一套好图标不只是"画个简笔画"那么简单。这篇文章分享专业图标设计的核心方法。

---

## 图标网格系统

### 像素网格对齐

图标应该在标准的像素网格上设计，最常用的是 **24×24** 或 **16×16**。所有主要 UI 库（Material Icons、Feather Icons、Lucide Icons）都用 24×24 的 viewBox：

```html
<svg viewBox="0 0 24 24" width="24" height="24">
```

### 关键线（Keylines）

在 24×24 的网格中：
- 内容区域：20×20（留 2px 内边距）
- 圆形图标稍微大一点可以视觉上跟方形图标对齐
- 水平线和垂直线尽量对齐到整数坐标

---

## 描边规范

### 描边宽度

对于 UI 图标，**2px 描边** 是最常用的标准。它保证了在各种屏幕尺寸下的可见性：

```html
stroke-width="2"
```

### 端点样式

- 使用 `stroke-linecap="round"` 让线条端点圆润
- 使用 `stroke-linejoin="round"` 让转角圆润

### 一致性原则

一套图标中的所有图标应该使用**相同的描边宽度、端点样式和转角样式**。混用不同风格的图标会让界面看起来不专业。

---

## 颜色策略

### 使用 `currentColor`

最佳实践是让图标继承文字颜色，而不是写死颜色值：

```html
<svg fill="none" stroke="currentColor" stroke-width="2">
```

这样图标可以跟随所在组件的颜色，深色模式下自动适配。

### 多色图标

如果需要多色图标，定义两个层级：
- `primary`：主要轮廓（继承 currentColor）
- `secondary`：强调色（可以写死或用 CSS 覆盖）

---

## 视觉平衡

### 光学权重

正方形、圆形、三角形在相同数学面积下看起来大小不同。需要调整：
- **圆形**略微放大以匹配方形的视觉重量
- **三角形**可能需要更大的面积才能跟方形"看起来一样大"

### 间距

图标之间的间距建议：
- 小图标（16px）：4-8px 间距
- 中图标（24px）：8-12px 间距
- 按钮中的图标：图标与文字间距 6-8px

---

## 导出检查清单

完成设计后，运行这个检查：
- [ ] viewBox 是 0 0 24 24（或其他标准尺寸）
- [ ] 所有图标使用统一描边宽度
- [ ] 颜色使用 currentColor（或统一色板）
- [ ] 没有无用的 id 或 data 属性
- [ ] 代码已经过优化（用 SVG 编辑器压缩）
- [ ] 在不同背景色下测试过
- [ ] 在 16px、24px、48px 三个尺寸下都清晰
