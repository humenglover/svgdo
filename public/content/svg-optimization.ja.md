## SVGが大きすぎる理由

FigmaやIllustratorから書き出したシンプルなアイコンが数十KB、時には数百KBになることを経験したことはありませんか？

問題はデザインではなく、**デザインツールが書き出すSVGに含まれる無駄**です。FigmaはコンポーネントIDやエディタのメタデータを追加します。Illustratorは各パスに超高精度の浮動小数点数（小数点以下6桁以上）を書き込みます。これらは不要ですが、ブラウザはすべて読み込まなければなりません。

## どのくらい削減できるか

テストデータに基づくと：

| ソース | 元のサイズ | 最適化後 | 削減率 |
|--------|----------|---------|--------|
| Figma出力 | 8.2 KB | 2.1 KB | 74.4% |
| Illustrator出力 | 15.6 KB | 3.4 KB | 78.2% |
| ダウンロードアイコン | 4.8 KB | 1.2 KB | 75.0% |
| Sketch出力 | 6.3 KB | 1.8 KB | 71.4% |

**平均70〜80%のファイルサイズ削減。**

## SVG肥大化の5大原因

### 1. XML宣言とコメント

```xml
<?xml version="1.0" encoding="utf-8"?>
<!-- Generator: Adobe Illustrator 26.0.0 -->
```

レンダリングには不要です。安全に削除できます。

### 2. 冗長な名前空間

```xml
xmlns:xlink="http://www.w3.org/1999/xlink"
```

モダンブラウザではxlink名前空間は不要になりました。

### 3. 不要なIDとdata属性

```html
id="Rectangle_1234" data-name="Rectangle 1234"
```

FigmaやSketchが全要素にタグ付けします。削除してもレンダリングに影響しません。

### 4. 過剰なパス精度

```html
d="M12.843792,45.218346 C12.843792..."
```

座標を小数点以下1〜2桁に丸めれば十分です。人の目では違いがわかりません。

### 5. 空の`<g>`グループタグ

デザインソフトが空のグループレイヤーを残します。無意味に容量を消費します。

## SVG最適化の方法

### 方法1：オンラインツールでワンクリック

最速の方法です。SVGエディタを開き、SVGコードを貼り付け、「安全」または「強力」モードを選択し、最適化をクリック — 数秒で完了です。

- **安全モード**：コメントとXML宣言のみ削除。レンダリングに影響なし
- **強力モード**：さらにパスを簡略化、空グループを削除、空白を圧縮

### 方法2：手動最適化

SVGコードに慣れている場合：
1. `<?xml>`宣言とコメントを削除
2. 未使用の`id`と`data-*`属性を削除
3. パス座標を小数点以下2桁に丸める
4. 最適化前後でレンダリングを比較
