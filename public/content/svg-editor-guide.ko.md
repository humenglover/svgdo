![SVG 에디터 메인 인터페이스](/content/images/editor-hero.png)

**SVG do.** 에 오신 것을 환영합니다 — 현대 프론트엔드 개발자와 디자이너를 위해 맞춤 제작된, 진정한 "클라우드 업로드 제로" 로컬 퍼스트 온라인 SVG 에디터입니다.

우리의 일상적인 개발 워크플로우에서 우리는 끊임없이 SVG를 미세 조정해야 합니다. 색상 변경, 테두리 제거 또는 온라인에서 찾은 비대한 SVG의 용량 최소화 등입니다. 그러나 대부분의 온라인 도구는 광고로 도배되어 있거나, 기밀 디자인 파일을 그들의 서버에 강제로 업로드하게 하거나, 심지어 가입하고 로그인하도록 요구합니다.

이것은 프론트엔드 도구의 원래 의도인 **미니멀리즘, 보안 및 효율성**에 완전히 위배됩니다.

우리 에디터의 핵심 철학은 간단합니다. 모든 것이 브라우저의 로컬 환경에서 일어납니다. 페이지를 닫으면 데이터는 파괴됩니다. 자, 이제 이 강력한 도구의 하드코어 기능들에 대해 깊이 파헤쳐 봅시다.

## 핵심 기능 1: "플러그 앤 플레이" 무한 아이콘 라이브러리

여전히 웹을 뒤져 오픈 소스 아이콘 라이브러리를 찾고, 다운로드하고, 수동으로 가져오고 계신가요? 우리는 3,500개 이상의 고품질 오픈 소스 아이콘을 포함하는 슈퍼 아스널을 에디터에 직접 통합했습니다.

![아이콘 라이브러리 열기](/content/images/editor-icon-library.png)

![분할 보기 들어가기](/content/images/editor-split-view.png)

![SVG 딥 압축](/content/images/editor-optimize-panel.png)

위의 애니메이션에서 보여주듯, 왼쪽 사이드바에서 <strong>아이콘 라이브러리</strong> (图标库) 를 클릭하기만 하면 됩니다. 모달을 탐색하거나 키워드(`apple`, `user`, `settings` 등)를 입력하세요. 완벽한 아이콘을 찾으면 단 한 번의 클릭으로 해당 소스 코드가 편집 패널에 즉시 주입됩니다.

이미 자신만의 디자인 에셋이 있더라도 모두 지원합니다:
1. `.svg` 파일을 웹 페이지로 직접 <strong>드래그 앤 드롭</strong> 하세요.
2. <strong>"업로드"를 클릭</strong> 하여 컴퓨터에서 로컬 파일을 선택하세요.
3. <strong>공개된 SVG URL을 붙여넣으면</strong> 에디터가 자동으로 코드를 가져옵니다.

## 핵심 기능 2: WYSIWYG "화면 분할" 몰입형 편집

대부분의 경우 SVG에 코드 수준의 조정을 해야 합니다. `fill` 색상을 수정하거나 특정 `<path>` 에 특정 CSS 클래스를 추가하여 Vue/React 프로젝트에서 제어할 수 있도록 해야 할 수도 있습니다.

왼쪽 상단의 <strong>분할 보기</strong> (分屏) 모드를 클릭하면 화면이 두 개로 완벽하게 나뉩니다:
- 왼쪽에는 <strong>구문 강조</strong> 및 <strong>자동 들여쓰기</strong> 기능을 갖춘 초고속 XML 코드 에디터가 있습니다.
- 오른쪽은 밀리초 수준의 응답 시간을 자랑하는 실시간 렌더링 미리보기 영역입니다.

코드에 입력하는 모든 문자나 수정하는 모든 `stroke-width` 픽셀은 오른쪽 캔버스에 즉시 다시 그려집니다. 개발자에게 이러한 직관적인 "코드가 곧 그림"이라는 피드백은 순수 시각적 도구로는 결코 대체할 수 없는 것입니다.

> <strong>다크 모드 미리보기:</strong> SVG가 흰색이거나 밝은 색상이면 표준 흰색 캔버스에서는 전혀 보이지 않을 수 있습니다. 걱정하지 마세요! 캔버스 오른쪽 상단 모서리에 있는 <strong>다크 모드 전환 버튼</strong> 을 클릭하면 즉시 어두운 배경이 깔리며 다크 UI 환경에서 어떻게 보일지 완벽하게 시뮬레이션할 수 있습니다.

## 핵심 기능 3: 비대함을 짜내는 "딥 압축 엔진"

디자이너가 Illustrator나 Figma에서 내보낸 SVG에는 엄청난 양의 "밀수품"이 포함되어 있는 경우가 많습니다. 쓸모없는 `<defs>` 더미, 디자인 소프트웨어 전용 `<metadata>`, 그리고 전혀 의미 없는 숨겨진 레이어들입니다. 이 쓰레기 코드는 웹 페이지 로딩 속도를 늦출 뿐만 아니라 HTML을 믿을 수 없을 정도로 흉측하게 만듭니다.

왼쪽의 <strong>최적화</strong> (优化) 패널을 확장하면 두 가지 킬러 옵션이 나타납니다:

1. <strong>안전 모드 (Safe Mode)</strong>: 가장 안전한 옵션입니다. 주석, 불필요한 공백, 줄 바꿈 및 쓸모없는 메타데이터만 제거합니다. SVG의 시각적 모양은 절대 변경하지 않습니다. 이것은 파일을 슬림하게 만드는 가장 안전한 방법입니다.
2. <strong>딥 압축 (Deep Compress)</strong>: 이것이 바로 진정한 흑마술입니다! 쓰레기 코드를 정리하는 것 외에도 기본적인 수학적 알고리즘을 사용하여 베지에 곡선을 병합하고, 보이지 않는 숨겨진 요소를 제거하며, 빈 속성을 지웁니다. 10KB 디자인 파일이 딥 압축 후 2KB로 직접 줄어드는 경우가 종종 있습니다. 파일 크기가 무려 80%나 대폭 감소하는 것입니다!

압축이 완료되면 <strong>최적화 전후의 바이트 차이</strong> 를 즉시 표시합니다. 프로젝트에 얼마나 많은 대역폭을 절약했는지 시각적으로 정확히 확인할 수 있습니다. 압축 결과가 만족스럽지 않다면(아주 드물게 극한의 압축으로 인해 복잡한 모양이 약간 변형될 수 있음), <strong>원본 복원</strong> 을 클릭하기만 하면 모든 것이 롤백됩니다.

## 핵심 기능 4: 원클릭 내보내기의 "차원을 넘는 일격"

우리는 단순한 에디터가 아니라 여러분의 개인 포맷 변환기입니다. 완벽한 SVG를 다듬었는데 갑자기 기획자가 달려와 "고해상도 PNG로 주세요"라고 말할 때, 더 이상 머리를 쥐어뜯을 필요가 없습니다.

<strong>내보내기</strong> (导出) 패널에서 진정한 원클릭 차원 변환을 경험할 수 있습니다:
- <strong>배수 스케일링 (1x / 2x / 4x)</strong>: 인쇄 또는 Retina 디스플레이용 초고화질 이미지가 필요한 경우 직접 4x를 선택하세요. 에디터는 먼저 메모리에서 벡터 그래픽을 무손실로 확대한 후 래스터화합니다. 내보낸 PNG는 과일을 자를 수 있을 정도로 가장자리가 날카롭습니다.
- <strong>스마트 배경 채우기</strong>: 내보낸 PNG는 기본적으로 투명한 배경을 갖습니다. 하지만 어두운 문서에 배치해야 하는 경우 원클릭으로 <strong>검은색</strong> 또는 <strong>흰색</strong> 으로 채우도록 선택할 수 있어 프레젠테이션에서 이미지가 "보이지 않는" 어색한 문제를 완벽하게 해결할 수 있습니다.

단순히 프로젝트에 붙여넣기 위해 <strong>SVG 코드를 복사</strong> 하거나, <strong>SVG 파일을 다운로드</strong> 하거나, <strong>고해상도 PNG를 내보내</strong> 려는 등 모든 것이 여러분을 기다리고 있습니다.

지금 코드 패널을 열고 아이콘을 드래그하여 SVG 마법의 여정을 시작하세요!
