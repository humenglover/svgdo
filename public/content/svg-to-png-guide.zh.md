## 为什么要把 SVG 转成 PNG？

![Article Illustration](https://images.unsplash.com/photo-1461749280684-dccba630e2f6?w=1200&q=80)

SVG 很好，但不是所有场景都适合 SVG。以下情况你需要 PNG：

- **邮件签名**：多数邮件客户端不支持 SVG
- **社交媒体头像**：部分平台的图片上传不接受 SVG
- **PPT 和文档**：Office 系列对 SVG 支持不完善
- **应用商店截图**：要求固定分辨率的 PNG
- **缩略图预览**：文件管理器通常无法预览 SVG

---

## 转换前要确认的三件事

### 1. 分辨率够不够？

PNG 是位图，分辨率写死了。如果你以后需要更大的尺寸，就得重新导出。

建议的策略：**导出时选择 2x 或 4x 倍率**，适配高清屏幕。

### 2. 需要透明背景吗？

SVG 默认是透明的。转 PNG 时可以选择：
- **透明背景**：适合叠加在其他元素上的图标
- **白色背景**：适合打印或文档嵌入
- **黑色背景**：适合深色 UI 环境

### 3. 颜色对不对？

SVG 中的 `currentColor` 在导出为 PNG 时可能丢失。确保在导出前用具体颜色值替换 `currentColor`。

---

## 使用在线工具转 PNG

### 步骤 1：加载 SVG
上传 SVG 文件，或从图标库加载，或粘贴 SVG 代码。

### 步骤 2：选择导出设置

- **倍率**：1x（原始）、2x（高清）、4x（超清）
- **背景**：透明 / 白色 / 黑色

### 步骤 3：导出
点击"导出 PNG"，浏览器会在本地渲染并下载 PNG 文件。

**整个过程在浏览器本地完成，SVG 代码不会上传到服务器。**

## 批量转换

如果需要转换大量 SVG，可以使用命令行工具：

```bash
# 安装 librsvg（macOS）
brew install librsvg

# 批量转换
for f in *.svg; do
  rsvg-convert -w 512 -h 512 "$f" -o "${f%.svg}.png"
done
```

或者用 ImageMagick：

```bash
for f in *.svg; do
  convert -background none -density 300 "$f" "${f%.svg}.png"
done
```

## SVG → PNG 质量对比

| 倍率 | 适用场景 | 文件大小 |
|------|---------|---------|
| 1x (24px) | 网页 favicon、小图标 | 最小 |
| 2x (48px) | 通用 UI、按钮图标 | 适中 |
| 4x (96px) | 头像、高清展示 | 较大 |
