## 什么是 SVG？

SVG 全称是 **Scalable Vector Graphics**，中文叫"可缩放矢量图形"。

和 PNG、JPEG 这些"位图"不同，SVG 不是用像素拼出来的画面。它是用数学公式描述图形的——一个圆是"圆心在 (100, 100)，半径 50"，一条线是"从 A 点画到 B 点"。

因为它是"算出来的"而不是"拍出来的"，所以 SVG 有一个独特的优势：**无论放大多少倍，画面永远清晰**。

---

## SVG 和位图的本质区别

| 特性 | SVG | PNG / JPEG |
|------|-----|-----------|
| 类型 | 矢量图 | 位图 |
| 缩放 | 无限缩放不失真 | 放大后出现锯齿 |
| 文件格式 | XML 文本 | 二进制数据 |
| 可编辑性 | 文本编辑器直接改 | 需要图像编辑软件 |
| 动画支持 | CSS / JavaScript 原生支持 | 需要 GIF/APNG/视频 |
| 适用场景 | 图标、Logo、插画、图表 | 照片、复杂渐变、纹理 |

## 为什么设计师推荐 SVG？

### 1. 永远清晰，一个文件通吃所有分辨率

再也不用为 Retina 屏单独切 @2x、@3x 的图了。一个 SVG 文件，从手机屏到 8K 显示器都清晰锐利。

### 2. 文件体积小

几十个图标的 SVG 加起来可能比一张高清 JPG 还小。SVG 是纯文本，压缩后体积极小，网页加载飞快。

### 3. 搜索引擎能"看懂"它

SVG 中的文字可以被搜索引擎索引，这对 SEO 来说是个巨大的加分。你的图标里如果有公司名、关键词，Google 都能读取。

### 4. 能动起来

通过 CSS 或 JavaScript，SVG 可以做旋转、变色、变形动画。它不是死的图片，而是活的组件。

## 打开一个 SVG 文件

你可以用三种方式打开 SVG：

1. **浏览器直接拖入** — Chrome/Edge/Firefox 都支持直接渲染 SVG
2. **文本编辑器** — VS Code、Sublime、记事本都能打开编辑 XML 代码
3. **专业工具** — Figma、Illustrator、Inkscape 可以可视化编辑

---

## 如何创建一个 SVG？

不需要安装昂贵的软件。打开浏览器，使用一个在线 SVG 编辑器就能开始画。你可以：

- 直接写 SVG 代码（XML 格式）
- 用可视化编辑器拖拽绘制
- 从图标库选择现成的图标

现在就去试试：打开我们的 SVG 编辑器，从图标库加载一个图标，看看它的代码长什么样，试着修改颜色和大小——你会立刻理解 SVG 的工作原理。
