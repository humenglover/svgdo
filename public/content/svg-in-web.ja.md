## 埋め込み方法が重要な理由

![Article Illustration](https://images.unsplash.com/photo-1507238691740-187a5b1d37b8?w=1200&q=80)

同じSVGアイコンでも、ウェブページへの埋め込み方によってまったく異なる振る舞いをします。

`<img>`タグを使えばシンプルですが色を変えられません。インラインSVGを使えば完全に制御できますがHTMLが肥大化します。各アプローチにトレードオフがあります。

---

## 5つの埋め込み方法の比較

### 1. インラインSVG

SVGコードを直接HTMLに書き込みます：

```html
<button>
  <svg viewBox="0 0 24 24"><path d="..."/></svg>
  保存
</button>
```

**利点**：CSSで色・サイズ制御可能、アニメーション対応、追加HTTPリクエストなし
**欠点**：HTMLが肥大化、ブラウザキャッシュ不可、コードの可読性低下

### 2. `<img>`タグ

```html
<img src="icon.svg" alt="保存アイコン" />
```

**利点**：最もシンプル、キャッシュ可能、遅延読み込み対応
**欠点**：CSSで色変更不可、インタラクション不可

### 3. CSS背景

```css
.icon { background: url('icon.svg') center/contain no-repeat; }
```

**利点**：装飾アイコンに最適、CSSと自然に統合
**欠点**：インタラクション不可

### 4. Data URI

```html
<img src="data:image/svg+xml;base64,..." />
```

**利点**：追加リクエストなし、小さなアイコンに適切
**欠点**：キャッシュ不可、URLが長い、メンテナンスが困難

### 5. SVGスプライト

```html
<svg><use href="/icons.svg#icon-name"></use></svg>
```

**利点**：1リクエストで全アイコン、キャッシュ可能
**欠点**：ビルドツールが必要

## ベストプラクティス

### ウェブサイトのロゴとコアUIアイコン → インラインSVG
インタラクティブでスタイル変更が必要。インラインが最大の柔軟性を提供。

### 装飾アイコン → CSS背景
インタラクティブでない装飾要素は背景として最もクリーン。

### 大規模アイコンライブラリ → SVGスプライト
数十〜数百のアイコンがある場合、スプライトが最も効率的。

### コンテンツ画像 → `<img>`タグ
SVGがコンテンツ（記事内のイラストなど）の場合、`<img>`が最良の互換性。

---

SVGエディタのコードビューでアイコンを開くと、完全なインラインコードが表示され、そのままHTMLにコピー＆ペーストできます。
