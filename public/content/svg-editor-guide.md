## Welcome to the Online SVG Editor

![Article Illustration](https://images.unsplash.com/photo-1498050108023-c5249f4df085?w=1200&q=80)

This is a complete guide to the online SVG editor. Whether you're a designer, frontend developer, or SVG beginner, this article will walk you through every feature from scratch.

---

## Step 1: Import SVG

Three ways to start editing:

### 1. Upload a File
Click the "Upload" button and select a `.svg` file from your computer. Or simply drag and drop the SVG file onto the editor.

### 2. Load from URL
Click URL, enter a publicly accessible SVG link. The editor automatically validates the URL, file type, and size before loading.

### 3. Pick from the Icon Library
Click "Icon Library" to browse over 3,500 SVG icons. Search by keyword, find the right icon, and click to load it.

---

## Step 2: Edit SVG

### Code Editor
The left panel features a code editor with syntax highlighting. You can directly modify the SVG XML — change colors, adjust dimensions, add elements.

Editing is real-time: any change you make in code instantly reflects in the preview panel on the right.

### Three View Modes

- **Split mode**: Code and preview side by side (recommended)
- **Preview mode**: Full-screen rendering view
- **Code mode**: Full-screen code editing

---

## Step 3: Transform Icons

In the "Transform" panel on the right, you can:

- **Rotate**: 90° / 180° / 270°
- **Flip**: Horizontal / Vertical

These operations recalculate path data in real-time and update the code.

---

## Step 4: Optimize & Compress

In the "Optimize" panel:

1. Choose mode: **Safe** (removes comments only) or **Aggressive** (removes bloat + simplifies paths)
2. Click "Optimize"
3. Compare file sizes before and after
4. If satisfied, copy the optimized code or continue editing
5. If not, click "Restore Original" to revert

---

## Step 5: Export

### Copy SVG Code
Click "Copy SVG" to copy the current SVG code to clipboard.

### Download SVG File
Click "Download SVG" to save as a `.svg` file.

### Export as PNG
In the "Export" panel, set the scale (1x/2x/4x) and background color (transparent/white/black), then export as PNG.

---

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl + Scroll` | Zoom preview |
| `Ctrl + +` | Zoom in |
| `Ctrl + -` | Zoom out |
| `Ctrl + 0` | Reset zoom |
| `Ctrl + Z` | Undo edit |

---

## Preview Settings

The toolbar lets you switch preview backgrounds:
- **Grid**: Great for alignment checks
- **Light**: Simulates light UI environments
- **Dark**: Simulates dark UI environments
