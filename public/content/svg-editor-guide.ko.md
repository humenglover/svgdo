## 온라인 SVG 에디터에 오신 것을 환영합니다

![Article Illustration](https://images.unsplash.com/photo-1498050108023-c5249f4df085?w=1200&q=80)

디자이너, 프론트엔드 개발자, SVG 초보자 상관없이 이 글에서 에디터의 모든 기능을 마스터할 수 있습니다.

---

## 1단계: SVG 가져오기

세 가지 방법으로 편집을 시작할 수 있습니다:

### 1. 파일 업로드
"업로드" 버튼을 클릭하고 컴퓨터에서 `.svg` 파일을 선택하세요. 또는 SVG 파일을 에디터에 직접 드래그 앤 드롭하세요.

### 2. URL에서 불러오기
URL 버튼을 클릭하고 공개된 SVG 링크를 입력하세요. 에디터가 URL 유효성, 파일 유형, 크기를 자동으로 검증한 후 로드합니다.

### 3. 아이콘 라이브러리에서 선택
"아이콘 라이브러리"를 클릭하여 3,500개 이상의 SVG 아이콘을 둘러보세요. 키워드 검색으로 적합한 아이콘을 찾아 클릭으로 로드하세요.

---

## 2단계: SVG 편집

### 코드 에디터
왼쪽 패널에 구문 강조 기능이 있는 코드 에디터가 있습니다. SVG의 XML을 직접 변경 — 색상 변경, 크기 조정, 요소 추가가 가능합니다.

편집은 실시간: 코드 변경 사항이 즉시 오른쪽 미리보기에 반영됩니다.

### 세 가지 보기 모드

- **분할 모드**: 코드와 미리보기를 좌우로 표시(권장)
- **미리보기 모드**: 전체 화면 렌더링 보기
- **코드 모드**: 전체 화면 코드 편집

---

## 3단계: 아이콘 변형

오른쪽 "변형" 패널에서:

- **회전**: 90° / 180° / 270°
- **반전**: 가로 / 세로

이러한 작업은 패스 데이터를 실시간으로 재계산하여 코드를 업데이트합니다.

---

## 4단계: 최적화 및 압축

"최적화" 패널에서:

1. 모드 선택: **안전** 또는 **강력**
2. "최적화" 클릭
3. 전후 파일 크기 비교
4. 만족하면 코드 복사, 불만족하면 "원본 복원"

---

## 5단계: 내보내기

- **SVG 코드 복사**: 현재 SVG 코드를 클립보드에 복사
- **SVG 파일 다운로드**: `.svg` 파일로 저장
- **PNG로 내보내기**: 배율(1x/2x/4x)과 배경색(투명/흰색/검은색) 설정 후 PNG로 내보내기

| 단축키 | 기능 |
|--------|------|
| `Ctrl + 스크롤` | 미리보기 확대/축소 |
