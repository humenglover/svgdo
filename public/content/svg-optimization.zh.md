## 你的 SVG 为什么那么大？

![Article Illustration](https://images.unsplash.com/photo-1555066931-4365d14bab8c?w=1200&q=80)

你有没有遇到过这种情况：一个简简单单的图标，从 Figma 或 Illustrator 导出来，竟然是几十 KB 甚至上百 KB？

问题不在你的设计，而在于**设计工具导出的 SVG 里塞满了垃圾代码**。Figma 会附加组件 ID、编辑器元数据、冗余的样式声明。Illustrator 会在每个路径上写入超精确浮点数（小数点后 6 位以上）。这些你不需要，但浏览器得全部加载。

## SVG 优化能减多少？

根据我们的测试数据：

| 来源 | 原始大小 | 优化后 | 压缩率 |
|------|---------|--------|--------|
| Figma 导出 | 8.2 KB | 2.1 KB | 74.4% |
| Illustrator 导出 | 15.6 KB | 3.4 KB | 78.2% |
| 网上下载的图标 | 4.8 KB | 1.2 KB | 75.0% |
| Sketch 导出 | 6.3 KB | 1.8 KB | 71.4% |

**平均能减少 70%-80% 的体积。**

## 最常见的 5 种 SVG 冗余

### 1. XML 声明和注释

```xml
<?xml version="1.0" encoding="utf-8"?>
<!-- Generator: Adobe Illustrator 26.0.0 -->
```

这些对渲染完全没用，可以安全删除。

### 2. 冗余的命名空间

```xml
xmlns:xlink="http://www.w3.org/1999/xlink"
xmlns:serif="http://www.serif.com/"
```

大多数现代浏览器不需要 xlink 命名空间了。

### 3. 无用的 id 和 data 属性

```html
id="Rectangle_1234" data-name="Rectangle 1234"
```

Figma 和 Sketch 给每个元素都加上 id，删掉不影响渲染。

### 4. 过高的路径精度

```html
d="M12.843792,45.218346 C12.843792..."
```

把路径坐标精简到小数点后 1-2 位就够了，肉眼完全看不出来。

### 5. 空的 `<g>` 组标签

设计软件经常留下空的图层组标签，占空间且毫无价值。

## 如何优化 SVG？

### 方法 1：用在线工具一键优化

这是最快的方法。打开 SVG 编辑器，粘贴你的 SVG 代码，选择"安全模式"或"深度压缩"，点击优化——几秒就搞定了。

- **安全模式**：只删注释和 XML 声明，不影响渲染
- **深度压缩**：额外精简路径、删空组、压缩空白

### 方法 2：手动优化

如果你熟悉 SVG 代码，可以直接：
1. 删掉 `<?xml>` 声明和注释
2. 移除无用的 `id` 和 `data-*` 属性
3. 用 SVGO 或类似工具批量处理
4. 压缩后对比渲染结果，确保没有破坏图形
