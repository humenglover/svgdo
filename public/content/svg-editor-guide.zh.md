## 欢迎使用在线 SVG 编辑器

![Article Illustration](https://images.unsplash.com/photo-1498050108023-c5249f4df085?w=1200&q=80)

这是一份完整的在线 SVG 编辑器使用指南。不管你是设计师、前端开发者，还是刚接触 SVG 的新手，这篇文章会带你从零开始掌握编辑器的全部功能。

---

## 第一步：导入 SVG

有三种方式可以开始编辑：

### 1. 上传文件
点击"上传"按钮，选择你电脑上的 `.svg` 文件。或者直接把 SVG 文件拖拽到编辑页面上。

### 2. 从 URL 加载
点击 URL 按钮，输入一个公开可访问的 SVG 链接。编辑器会自动验证链接有效性、文件类型和大小，然后加载到编辑器中。

### 3. 从图标库选择
点击"图标库"，浏览超过 3500 个 SVG 图标。支持关键词搜索，找到合适的图标后点击即可加载。

---

## 第二步：编辑 SVG

### 代码编辑器
左侧是代码编辑器，支持语法高亮。你可以直接修改 SVG 的 XML 代码——改颜色、调整尺寸、添加元素。

编辑是实时同步的：你在代码中的任何修改，右侧预览区都会立刻反映出来。

### 三种视图模式

- **分屏模式**：左右同时显示代码和预览（推荐）
- **预览模式**：全屏查看渲染效果
- **代码模式**：全屏编辑代码

---

## 第三步：变换图标

在右侧"变换"面板中，你可以：

- **旋转**：90° / 180° / 270°
- **翻转**：水平翻转 / 垂直翻转

这些操作会实时计算新的 path 数据并更新代码。

---

## 第四步：优化压缩

在"优化"面板中：

1. 选择模式：**安全模式**（只删注释）或 **深度压缩**（删冗余+精简路径）
2. 点击"优化"
3. 查看优化前后的大小对比
4. 如果满意，复制优化后的代码或继续编辑
5. 如果不满意，点击"恢复原始"回退

---

## 第五步：导出

### 复制 SVG 代码
点击"复制 SVG"即可将当前的 SVG 代码复制到剪贴板。

### 下载 SVG 文件
点击"下载 SVG"保存为 `.svg` 文件。

### 导出为 PNG
在"导出"面板中设置倍率（1x/2x/4x）和背景色（透明/白/黑），然后导出为 PNG。

---

## 快捷键速查

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + 滚轮` | 缩放预览 |
| `Ctrl + +` | 放大 |
| `Ctrl + -` | 缩小 |
| `Ctrl + 0` | 重置缩放 |
| `Ctrl + Z` | 撤销编辑 |

---

## 预览设置

工具栏右侧可以切换预览背景：
- **网格**：方便检查对齐
- **白底**：模拟浅色 UI 环境
- **黑底**：模拟深色 UI 环境
