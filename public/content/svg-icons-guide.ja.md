## 良いアイコンデザインが重要な理由

アイコンはユーザーインターフェースの「サイレント言語」です。優れたアイコンセットは、プロダクトをプロフェッショナルで一貫性があり、信頼できるものに見せます。

SVGはアイコンデザインの自然な形式ですが、優れたアイコンセットのデザインは「単純な形を描く」以上のものです。

---

## アイコングリッドシステム

### ピクセルグリッドの整列

アイコンは標準的なピクセルグリッド上でデザインすべきです。最も一般的なのは**24×24**または**16×16**です。すべての主要UIライブラリ（Material Icons、Feather Icons、Lucide Icons）は24×24のviewBoxを使用します：

```html
<svg viewBox="0 0 24 24" width="24" height="24">
```

### キーライン

24×24グリッドでは：
- コンテンツエリア：20×20（四方に2pxのパディング）
- 円形アイコンは正方形アイコンと視覚的にバランスを取るためにわずかに大きく
- 水平線と垂直線は整数座標に揃える

---

## ストローク仕様

### ストローク幅

UIアイコンでは**2pxストローク**が最も一般的な標準です：

```html
stroke-width="2"
```

### 線端と線結合

- `stroke-linecap="round"`で線端を丸く
- `stroke-linejoin="round"`で角を丸く

### 一貫性

セット内のすべてのアイコンは**同じストローク幅、線端、線結合スタイル**を使用すべきです。異なるスタイルの混在はプロらしくありません。

## カラー戦略

### `currentColor`を使う

ベストプラクティス：値をハードコードする代わりに、テキスト色を継承させます：

```html
<svg fill="none" stroke="currentColor" stroke-width="2">
```

これにより、ダークモード含め、親コンポーネントの色に自動的に一致します。

### マルチカラーアイコン

マルチカラーアイコンの場合、2階層を定義します：
- `primary`：メインアウトライン（currentColorを継承）
- `secondary`：アクセントカラー（ハードコードまたはCSS上書き可能）

## エクスポートチェックリスト

納品前にこのチェックを実行：
- [ ] viewBoxが`0 0 24 24`（または他の標準サイズ）
- [ ] 全アイコンが一貫したストローク幅を使用
- [ ] 色に`currentColor`（または統一パレット）を使用
- [ ] 不要な`id`や`data-*`属性がない
- [ ] コードが最適化されている（SVGエディタで圧縮）
- [ ] 異なる背景色でテスト済み
- [ ] 16px、24px、48pxで鮮明

SVGエディタを使って最後の2ステップを完了しましょう — アイコンを読み込み、プレビュー背景を切り替え、異なるズームレベルで確認します。
