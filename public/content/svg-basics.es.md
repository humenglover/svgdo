## ¿Qué es SVG?

SVG significa **Scalable Vector Graphics** (Gráficos Vectoriales Escalables).

A diferencia de PNG y JPEG — que son cuadrículas de píxeles — SVG describe imágenes matemáticamente: un círculo es "centro en (100,100), radio 50". Una línea es "desde el punto A al punto B".

Porque se calcula en lugar de grabarse, SVG tiene un superpoder único: **nunca se ve borroso, sin importar cuánto lo amplíes.**

---

## SVG vs Raster: La diferencia clave

| Característica | SVG | PNG / JPEG |
|----------------|-----|-------------|
| Tipo | Vector | Raster (píxeles) |
| Escalado | Infinito, sin pérdida | Bordes dentados al ampliar |
| Formato de archivo | Texto XML | Datos binarios |
| Editable | Cualquier editor de texto | Necesita software de edición |
| Animación | CSS/JS nativo | Necesita GIF/APNG/video |
| Ideal para | Iconos, logos, ilustraciones | Fotos, gradientes complejos |

## Por qué los diseñadores aman SVG

### 1. Siempre nítido — Un archivo, todas las resoluciones

Olvídate de exportar variantes @2x y @3x para pantallas Retina. Un solo archivo SVG se ve nítido desde un teléfono hasta un monitor 8K.

### 2. Archivos increíblemente pequeños

Docenas de iconos SVG juntos pueden pesar menos que un solo JPEG de alta resolución.

### 3. Los motores de búsqueda pueden leerlo

El texto dentro de los SVG es indexable por Google. Si tu icono contiene una marca, Google puede leerlo.

### 4. Está vivo — No es estático

Con CSS y JavaScript, los SVG pueden rotar, cambiar de color y animarse.
