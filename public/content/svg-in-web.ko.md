## 임베딩 방법이 중요한 이유

동일한 SVG 아이콘이라도 웹페이지에 임베딩하는 방법에 따라 완전히 다르게 동작합니다.

---

## 5가지 임베딩 방법 비교

### 1. 인라인 SVG
HTML에 직접 SVG 코드를 작성합니다.

**장점**: CSS로 색상/크기 제어 가능, 애니메이션 지원, 추가 HTTP 요청 없음
**단점**: HTML 비대화, 브라우저 캐시 불가

### 2. `<img>` 태그
**장점**: 가장 단순, 캐시 가능, 지연 로딩 지원
**단점**: CSS로 색상 변경 불가

### 3. CSS 배경
**장점**: 장식 아이콘에 최적
**단점**: 인터랙션 불가

### 4. Data URI
**장점**: 추가 요청 없음
**단점**: 캐시 불가, URL이 김

### 5. SVG 스프라이트
**장점**: 하나의 요청으로 모든 아이콘 로드
**단점**: 빌드 도구 필요

---

## 베스트 프랙티스

- **로고와 코어 UI 아이콘 → 인라인 SVG**
- **장식 아이콘 → CSS 배경**
- **대규모 아이콘 라이브러리 → SVG 스프라이트**
- **콘텐츠 이미지 → `<img>` 태그**

SVG 에디터의 코드 뷰에서 아이콘을 열면 완전한 인라인 코드가 표시되어 바로 HTML에 붙여넣을 수 있습니다.
