## What Is SVG?

SVG stands for **Scalable Vector Graphics**.

Unlike PNGs and JPEGs — which are grids of colored pixels — SVG describes images mathematically: a circle is defined as "center at (100, 100), radius 50." A line is "from point A to point B."

Because it's computed rather than recorded, SVG has one unique superpower: **it never gets blurry, no matter how much you zoom in.**

---

## SVG vs Raster: The Core Difference

| Feature | SVG | PNG / JPEG |
|---------|-----|-----------|
| Type | Vector | Raster (pixels) |
| Scaling | Infinite, lossless | Jagged edges when enlarged |
| File format | XML text | Binary data |
| Editability | Any text editor | Image editing software needed |
| Animation | Native CSS / JS support | Requires GIF/APNG/video |
| Best for | Icons, logos, illustrations, charts | Photos, complex gradients, textures |

## Why Designers Love SVG

### 1. Always Sharp — One File, Every Resolution

Forget exporting @2x and @3x variants for Retina displays. One SVG file looks crisp from a phone screen to an 8K monitor.

### 2. Tiny File Sizes

Dozens of SVG icons together can weigh less than a single high-res JPEG. Plain text compresses beautifully — pages load faster.

### 3. Search Engines Can Read It

Text inside SVGs is indexable by search engines. If your icon contains a brand name or keyword, Google can read and rank it. This is a massive SEO advantage.

### 4. It's Alive — Not Static

With CSS and JavaScript, SVGs can rotate, change color, morph, and animate. It behaves like a component, not a dead image file.

## How to Open an SVG File

Three ways:

1. **Drag into a browser** — Chrome, Edge, and Firefox all render SVG natively
2. **Use a text editor** — VS Code, Sublime, or even Notepad can open the XML
3. **Professional tools** — Figma, Illustrator, Inkscape for visual editing

## How to Create an SVG

No expensive software required. Open a browser and use an online SVG editor. You can:

- Write SVG code directly (XML format)
- Use a visual editor to draw shapes
- Pick icons from a built-in icon library
