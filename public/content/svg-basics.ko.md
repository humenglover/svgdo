## SVG란?

SVG는 **Scalable Vector Graphics**의 약자입니다.

PNG나 JPEG과 같은 픽셀의 집합과 달리, SVG는 수식으로 이미지를 기술합니다. 원은 "중심(100,100), 반지름 50", 선은 "점 A에서 점 B로"와 같이 말이죠.

계산으로 그려지기 때문에 SVG에는 유일무이한 강점이 있습니다: **아무리 확대해도 절대 깨지지 않습니다.**

---

## SVG vs 래스터: 핵심 차이

| 특징 | SVG | PNG / JPEG |
|------|-----|-----------|
| 유형 | 벡터 | 래스터(픽셀) |
| 확대/축소 | 무한, 무손실 | 확대 시 계단 현상 |
| 파일 형식 | XML 텍스트 | 바이너리 데이터 |
| 편집 | 텍스트 에디터로 가능 | 이미지 편집 소프트웨어 필요 |
| 애니메이션 | CSS/JS 네이티브 지원 | GIF/APNG/비디오 필요 |
| 적합한 용도 | 아이콘, 로고, 일러스트, 차트 | 사진, 복잡한 그라데이션 |

## 디자이너가 SVG를 사랑하는 이유

### 1. 항상 선명 — 하나의 파일로 모든 해상도 대응

레티나용 @2x, @3x를 따로 내보낼 필요가 없습니다. 하나의 SVG 파일로 스마트폰부터 8K 모니터까지 선명하게 표시됩니다.

### 2. 놀라울 정도로 작은 파일 크기

수십 개의 SVG 아이콘이 고해상도 JPEG 한 장보다 가볍습니다. 일반 텍스트는 압축 효율이 높아 페이지 로딩이 빨라집니다.

### 3. 검색 엔진이 읽을 수 있음

SVG 내의 텍스트는 검색 엔진에 색인됩니다. 브랜드명이나 키워드가 포함되어 있으면 Google이 읽고 순위를 매깁니다.

### 4. 살아있는 그래픽

CSS와 JavaScript로 SVG는 회전, 색상 변경, 변형, 애니메이션이 가능합니다. 죽은 이미지 파일이 아닌 살아있는 컴포넌트로 작동합니다.

---

SVG 에디터를 열어 라이브러리에서 아이콘을 불러오고, 코드를 확인하고, 색상과 크기를 변경해보세요 — SVG의 작동 원리를 바로 이해할 수 있을 것입니다.
