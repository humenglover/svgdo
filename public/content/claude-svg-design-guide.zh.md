## 第二式：通用提示词模板（Prompt 核心）

光会喊“帮我画个图”是没用的。Claude 也是个程序员，你得给它精准的需求。我总结了一套万能的 SVG 生成提示词模板：

> **“你是一个资深的前端工程师和 UI 设计师。请使用纯 SVG 绘制一个 [描述你需要的内容]。**
> 
> **具体要求如下：**
> **1. 尺寸：[比如 viewBox="0 0 800 600"]**
> **2. 风格：[比如 极简主义、扁平化、玻璃拟物风、赛博朋克]**
> **3. 配色：[指定色值，比如使用 #1e293b 作为背景，主色调是 #3b82f6]**
> **4. 细节：[需要包含的具体元素，如阴影效果、圆角、特定的文本]**
> 
> **请只输出格式良好的、可直接渲染的 SVG 代码，不要多余的解释。”**

### 实战演示：画一个现代风的数据面板

如果你把上述模板套用一下，让它画个数据 Dashboard 的占位图：

```text
你是一个资深的前端工程师和 UI 设计师。请使用纯 SVG 绘制一个现代风的数据面板占位图。

具体要求如下：
1. 尺寸：viewBox="0 0 1000 600"
2. 风格：毛玻璃风格 (Glassmorphism)，背景带有深色渐变
3. 配色：深邃蓝背景，面板卡片使用带有透明度的白色，数据高亮使用荧光绿和荧光紫。
4. 细节：包含一个带曲线的折线图、一个半圆环图表，以及一些虚拟的文字占位。

请只输出格式良好的 SVG 代码，不要多余的解释。
```

拿到代码后，直接贴进咱们的编辑器里，你会发现效果好得出奇。这就是 AI 的力量。

![Typing prompts like a hacker](/content/images/svg-ai-guide/meme-hacker-typing.gif)

## 第三式：结合平台进行“精修”

Claude 虽然很强，但它毕竟是个瞎子（大模型看不见自己的输出效果）。它有时候会把几个图层叠错，或者文字稍微超出了边界。

这时候，平台的作用就完全体现出来了！
看看我们在编辑器里做二次调整的状态：

![Real Platform Usage 2](/content/images/svg-ai-guide/platform-usage-2.png)

你在平台上可以非常直观地：
1. **微调坐标**：把偏离的 `cx`, `cy` 参数改一改。
2. **替换色彩**：如果你觉得 AI 选的颜色太丑，直接在编辑器里把它换成你的品牌色。
3. **添加交互**：如果你想让这个 SVG 动起来，直接在代码里加上 `<animate>` 标签，或者导出之后再配合外部 CSS 和 JS。

我们的编辑器支持实时渲染，这意味着你可以和 Claude 进行“结对编程”。Claude 负责输出大框架，你负责在编辑器里抠细节。这简直是 1+1 > 2 的组合。

## 避坑指南：别太相信 AI 的“复杂几何”

虽然我说得很玄乎，但必须要提醒大家，Claude 在处理**非常复杂的不规则矢量插画**（比如一幅完整的人物油画）时，表现会非常智障。
它会写出成千上万行的 `<path>`，然后整个浏览器卡得像幻灯片，最后画出来的东西像毕加索的早期作品——抽象得你根本认不出是什么鬼东西。

所以，记住了：
1. **不要让 AI 画脸**。除非你需要恐怖片素材。
2. **专注于几何图形、图表、UI 组件、简单的 Logo 和图标**。这是它最擅长的领域。
3. **遇到问题，拆分需求**。不要让它一次性画个宇宙，让它先画个太阳，再画个地球。

总而言之，保持清醒，AI 是工具，不是万能药。
