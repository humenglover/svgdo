欢迎来到 **SVG do.** —— 一个为现代前端开发者和设计师量身打造的、真正“零云端上传”的本地化 SVG 在线编辑器。

在日常开发中，我们常常需要对 SVG 进行微调：改个颜色、去个边框、或者是把网上找来的臃肿 SVG 压缩一下。但是，大多数在线工具要么满屏广告，要么强迫你把机密的设计稿上传到他们的服务器，甚至还要注册登录。

这就违背了前端开发的初衷：**极简、安全、高效**。

我们打造这个编辑器的核心理念就是：一切都在你的浏览器本地发生。关闭页面，数据即焚。接下来，让我们深入了解这款神器的硬核用法。

正如上面的动图演示，你只需要点击左侧栏的 <strong>图标库</strong>，在弹出的窗口中随意浏览，或者输入关键词（比如 `apple`、`user`、`settings`）。找到心仪的图标后，只需轻轻一点，这个图标的源码就会瞬间注入到你的编辑面板中。

## 核心能力二：所见即所得的“分屏沉浸式”编辑

很多时候，我们需要对 SVG 进行代码级的微调。比如修改 <code>fill</code> 颜色，或者给某个特定的 <code>&lt;path&gt;</code> 加上一个特殊的 class 类名以便于在前端项目中用 CSS 控制。

在左上角点击 <strong>分屏</strong>（Split View）模式后，你的屏幕会被完美一分为二：
- 左侧是带有**极速语法高亮**和**自动缩进**的 XML 代码编辑器。
- 右侧是毫秒级响应的实时渲染预览区。

你在代码里敲击的每一个字符、修改的每一个 <code>stroke-width</code> 像素，都会在右侧的画布上实时重绘。对于开发者来说，这种“代码即画面”的直觉反馈，是任何纯视觉工具都无法替代的。

> <strong>暗黑模式预览：</strong> 如果你的 SVG 是白色或浅色的，放在白底画布上可能什么都看不见。不用担心，点击画布右上角的 <strong>暗黑模式切换按钮</strong>，就能一秒给画布铺上深色底色，完美模拟深色 UI 环境下的真实显示效果。

## 核心能力三：榨干冗余代码的“深度压缩引擎”

设计师从 Illustrator 或 Figma 导出的 SVG，往往携带了海量的“私货”：一堆无用的 `<defs>`、设计软件专属的 `<metadata>`、以及毫无意义的隐藏图层。这些垃圾代码不仅拖慢网页加载速度，还会把你的 HTML 塞得奇丑无比。

展开左侧的 <strong>优化</strong>（Optimize）面板，你将看到两个杀手级选项：

1. <strong>安全模式（Safe Mode）</strong>：最稳妥的选项。它仅仅剥离注释、多余的空格换行和无用的元数据。它绝对不会改变 SVG 的真实长相，是最安全的瘦身方式。
2. <strong>深度压缩（Deep Compress）</strong>：这才是真正的黑科技！除了清理垃圾代码，它还会利用底层算法对贝塞尔曲线进行数学级合并，移除不可见的隐藏元素，并且抹除空属性。一个 10KB 的设计稿，经过深度压缩后，往往能直接缩减到 2KB，体积缩小高达 80%！

在压缩完成后，我们会直接给你展示 <strong>优化前后的字节差异</strong>。你可以直观地看到为项目节省了多少带宽。如果你对压缩后的效果不满意（极少数情况下会导致复杂图形变形），只需点击 <strong>恢复原始</strong>，一切都能回退。

## 核心能力四：一键切图的“跨维打击”

我们不仅是个编辑器，更是你的专属格式转换器。当你处理完一个完美的 SVG，但产品经理突然跑过来说：“给我一张高清的 PNG”时，你再也不用抓狂了。

在 <strong>导出</strong> 面板中，你可以体验到真正的一键跨维转换：
- <strong>倍率放大（1x / 2x / 4x）</strong>：如果你需要一张极其清晰的图片用于印刷或 Retina 高分屏，直接选择 4x。编辑器会先在内存中将矢量图无损放大，然后再渲染，导出的 PNG 边缘锋利得能切水果。
- <strong>智能底色填充</strong>：导出的 PNG 背景默认是透明的。但如果需要放在深色文档里，你可以一键选中填充 <strong>黑色</strong> 或 <strong>白色</strong>，彻底解决在 PPT 中图片“隐形”的尴尬问题。

不管你是想直接 <strong>复制 SVG 代码</strong> 丢进 Vue/React 项目里，还是 <strong>下载 SVG 文件</strong>，又或是 <strong>导出高清 PNG</strong>，这里都为你准备好了一切。

赶紧打开代码面板，拖入一个图标，开始你的 SVG 魔法之旅吧！
