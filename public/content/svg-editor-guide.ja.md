![SVG エディターのメインインターフェース](/content/images/editor-hero.png)

**SVG do.** へようこそ。これは、現代のフロントエンド開発者やデザイナーのためにカスタマイズされた、真の「クラウドへのアップロード不要」、ローカルファーストなオンライン SVG エディターです。

毎日の開発ワークフローの中で、私たちは常に SVG に微調整を加える必要があります。色を変えたり、境界線を消したり、ネットで見つけた肥大化した SVG を軽量化したり。しかし、ほとんどのオンラインツールは、広告だらけだったり、機密のデザインファイルを彼らのサーバーにアップロードすることを強制したり、あるいは登録してログインすることさえ要求します。

これは、フロントエンドツールの本来の意図である「**ミニマリズム、セキュリティ、そして効率性**」に完全に反しています。

私たちのエディターの背後にある核となる哲学はシンプルです。すべてはあなたのブラウザのローカルで完結します。ページを閉じれば、データは破壊されます。それでは、この強力なツールのハードコアな機能について深く掘り下げてみましょう。

## コア機能 1: 「プラグアンドプレイ」な無限のアイコンライブラリ

まだオープンソースのアイコンライブラリをウェブで探し回り、ダウンロードしてから手動でインポートしていますか？私たちは、3,500以上の高品質なオープンソースアイコンのスーパーアーセナルをエディターに直接統合しました。

![アイコンライブラリを開く](/content/images/editor-icon-library.png)

![分割表示に入る](/content/images/editor-split-view.png)

![SVGの深層圧縮](/content/images/editor-optimize-panel.png)

上のアニメーションが示すように、左のサイドバーにある <strong>アイコンライブラリ</strong> (图标库) をクリックするだけです。モーダルを見るか、キーワード（`apple`、`user`、`settings` など）を入力します。完璧なアイコンを見つけたら、1回クリックするだけで、そのソースコードが編集パネルに即座に注入されます。

独自のデザインアセットをすでにお持ちの場合でも、それらをサポートしています：
1. 任意の `.svg` ファイルをウェブページに直接 <strong>ドラッグ＆ドロップ</strong> します。
2. <strong>「アップロード」をクリック</strong> して、コンピューターからローカルファイルを選択します。
3. <strong>公開されている SVG URL を貼り付ける</strong> と、エディターが自動的にコードを取得してくれます。

## コア機能 2: WYSIWYG な「分割画面」の没入型編集

多くの場合、SVG にコードレベルの調整を行う必要があります。`fill` の色を変更したり、特定の `<path>` に特定の CSS クラスを追加して Vue/React プロジェクトで制御できるようにしたりする必要があるかもしれません。

左上の <strong>分割表示</strong> (分屏) モードをクリックすると、画面が完璧に左右に分割されます：
- 左側には、<strong>シンタックスハイライト</strong> と <strong>オートインデント</strong> を備えた、超高速の XML コードエディターが表示されます。
- 右側には、ミリ秒単位の応答時間を持つリアルタイムレンダリングのプレビューエリアが表示されます。

コードに入力するすべての文字や、変更するすべての `stroke-width` ピクセルは、右側のキャンバスに即座に再描画されます。開発者にとって、この直感的な「コードがそのまま画像になる」というフィードバックは、純粋なビジュアルツールでは決して代用できないものです。

> <strong>ダークモードプレビュー:</strong> SVG が白や明るい色の場合、標準的な白いキャンバスの上では完全に見えなくなる可能性があります。心配はいりません！キャンバスの右上隅にある <strong>ダークモード切り替えボタン</strong> をクリックするだけで、暗い背景が即座に敷き詰められ、ダーク UI 環境でどのように表示されるかを完璧にシミュレートできます。

## コア機能 3: 肥大化を絞り出す「ディープコンプレス（深層圧縮）エンジン」

デザイナーによって Illustrator や Figma からエクスポートされた SVG には、大量の「密輸品」が持ち込まれることがよくあります。無駄な `<defs>` の山、デザインソフトウェア特有の `<metadata>`、そして全く意味のない隠しレイヤーなどです。このガベージコードは、ウェブページの読み込み速度を低下させるだけでなく、HTML を信じられないほど醜くします。

左側の <strong>最適化</strong> (优化) パネルを展開すると、2つの強力なオプションが表示されます：

1. <strong>セーフモード (Safe Mode)</strong>: 最も安全なオプションです。コメント、冗長なスペース、改行、および無駄なメタデータのみを取り除きます。SVG の視覚的な外観を変更することは絶対にありません。これは、ファイルをスリム化するための最も安全な方法です。
2. <strong>ディープコンプレス (Deep Compress)</strong>: これが本当の黒魔術です！ガベージコードをクリーンアップするだけでなく、基礎となる数学的アルゴリズムを使用してベジェ曲線をマージし、目に見えない隠し要素を削除し、空の属性を消去します。10KB のデザインファイルが、ディープコンプレス後には 2KB にまで直接削減されることがよくあります。ファイルサイズが 80% も劇的に縮小されるのです！

圧縮が完了すると、<strong>最適化前後のバイト単位の差</strong> が即座に表示されます。プロジェクトの帯域幅をどれだけ節約できたかを視覚的に正確に確認できます。圧縮結果に満足できない場合（ごくまれに、極端な圧縮によって複雑な形状がわずかに歪むことがあります）、<strong>元に戻す</strong> をクリックするだけで、すべてがロールバックされます。

## コア機能 4: ワンクリックエクスポートの「次元を超えた一撃」

私たちは単なるエディターではありません。あなたのパーソナルなフォーマットコンバーターでもあります。完璧な SVG を磨き上げたのに、プロダクトマネージャーが突然駆け寄ってきて「高解像度の PNG をちょうだい」と言ってきた時、もう二度と頭を抱える必要はありません。

<strong>エクスポート</strong> (导出) パネルでは、真のワンクリックな次元変換を体験できます：
- <strong>乗数スケーリング (1x / 2x / 4x)</strong>: 印刷や Retina ディスプレイ用の超鮮明な画像が必要な場合は、直接 4x を選択します。エディターは、ラスタライズする前に、まずメモリ内でベクターグラフィックをロスレスで拡大します。エクスポートされた PNG は、果物が切れるほど鋭いエッジを持ちます。
- <strong>スマート背景塗りつぶし</strong>: エクスポートされた PNG は、デフォルトで透明な背景を持っています。しかし、暗いドキュメントに配置する必要がある場合は、ワンクリックで <strong>黒</strong> または <strong>白</strong> で塗りつぶすことを選択でき、プレゼンテーションでの画像の「不可視化」という厄介な問題を完全に解決できます。

プロジェクトに貼り付けるために単に <strong>SVG コードをコピー</strong> したい場合でも、<strong>SVG ファイルをダウンロード</strong> したい場合でも、<strong>高解像度の PNG をエクスポート</strong> したい場合でも、ここにはすべてが用意されており、あなたを待っています。

今すぐコードパネルを開き、アイコンをドラッグして、SVG の魔法の旅を始めましょう！
